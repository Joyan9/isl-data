How we calculate

For every non-own-goal shot with xG, we treat xG as an independent Bernoulli probability and convolve those probabilities into an exact goal distribution. Match xPts is 3 × win probability + draw probability. Actual goals use credited_team_id, so an own goal counts for the benefiting team; own goals are excluded from xG. Early-season numbers are noisy: small samples should not start a war.
